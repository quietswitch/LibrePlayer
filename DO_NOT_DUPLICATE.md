# Do Not Duplicate

## Already Implemented Here

- Local library scan from `MediaStore`
- Optional SAF folder import
- Songs, albums, artists, playlists, favorites, and recently played
- Search
- Queue playback with shuffle/repeat and background media controls
- Persistent playback restore
- Audio Details for tags and technical properties
- Artwork loading across core playback and library surfaces

## Keep In Other Apps

- Streaming clients
- Podcast or audiobook-specific players
- Cloud library/sync systems
- Desktop tag editors or bulk file-management tools
- Media servers, transcoding tools, or network-sharing apps

## Considered But Intentionally Deferred

- Folder view
- Rich queue editing
- Lyrics
- Casting
- Recommendation features
- Advanced metadata editing

## Legacy Or Replaced Repos

No legacy or replaced repo is documented in this repo. Treat LibrePlayer as the active Android local-player codebase.

## This App Is Not For

- People looking for streaming music services
- Multi-device cloud library management
- Large-scale file tagging and library repair
- Podcast, audiobook, or radio-first workflows
